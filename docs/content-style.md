# MonsterWrite Content & Voice

How MonsterWrite talks. Warm, literary, calm — like a thoughtful friend who keeps a
beautiful notebook. The whimsy lives in the monsters, not in punctuation or emoji.

---

## Core rules

- **Person:** second person to the writer ("you", "your words"), third person about the
  monster ("Wisper is hungry", "it flourishes when you write").
- **Case:** sentence case everywhere — buttons, headings, labels, copy. The **only**
  exception is UPPERCASE section labels with wide tracking (`tracking-[0.16em]`), e.g.
  `STATS`, `WRITING HISTORY`, `SETTINGS`, `BADGES`.
- **Tone:** warm, literary, calm. No hype, no exclamation pileups, no marketing shout.
- **No emoji. Ever.** Not in UI, copy, badges, notifications, or commit-facing strings.
  Whimsy comes from the monsters' art and personalities.
- **Numbers:** plain digits ("512 words", "7 day streak"). Rendered in `font-mono`.

---

## Canonical strings

- **Tagline:** `Feed your monster. Build your habit.`
- **Goal met (CTA / banner):** `Goal complete` (not "Goal Complete! 🎉").
- **Primary CTA:** `Start writing` / when met: `Feed your monster`.

### Mood words (monster wellbeing — flourishing → fading)

| State      | Word        |
| ---------- | ----------- |
| ecstatic   | Flourishing |
| happy      | Content     |
| neutral    | Getting by  |
| sad        | Hungry      |
| distressed | Fading      |

### Hunger words (HungerBar — full → empty)

| Fullness | Word     |
| -------- | -------- |
| high     | Full     |
| good     | Content  |
| low      | Peckish  |
| empty    | Starving |

---

## Examples

| Do                                          | Don't                                  |
| ------------------------------------------- | -------------------------------------- |
| `Start writing`                             | `START WRITING NOW!!`                  |
| `Goal complete`                             | `Goal Complete! 🎉`                    |
| `Wisper is getting by.`                     | `Your monster is doing okay 😐`        |
| `You wrote 512 words today.`                | `You crushed 512 words! 🔥`            |
| `Feed your monster`                         | `FEED ME`                              |
| `STATS` (section label, wide-tracked)       | `Stats!!!`                             |

When in doubt: quieter, warmer, lower case. Let the monster carry the personality.
